🩸 Blood Bank Management System

📌 Project Description

The Blood Bank Management System is a Python-based project designed to manage blood donor information and maintain donor records. It helps store and organize donor details, making blood bank management easier and more efficient.

🎯 Objectives

To maintain blood donor records.

To store donor information systematically.

To make donor information easy to access.

To reduce manual record-keeping work.

To support efficient blood bank management.


✨ Features

Add and manage donor details.

Store donor information in a text file.

View and maintain donor records.

Simple and user-friendly interface.

Organized donor data management.

🛠️ Technologies Used

Programming Language: Python

Storage: Text File (donors.txt)

Version Control: Git

Platform: GitHub
